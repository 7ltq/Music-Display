# Music Display

A modern Minecraft music HUD with synchronized lyrics and a Liquid Glass interface.

## Features
- Spotify and Apple Music integration
- Synchronized lyrics with karaoke animations
- Album artwork and dynamic colors
- Mini HUD and expanded music player
- Playback controls
- Customizable appearance powered by WalksyLib

## Requirements
- Minecraft 26.3
- Fabric
- Windows for media integration
- WalksyLib

## Installation
1. Install Fabric for Minecraft 26.3.
2. Install the required dependencies.
3. Download Music Display from Modrinth.
4. Place the mod JAR in your Minecraft mods folder.
